## ✨ Características Técnicas
- **Motor Gráfico:** HTML5 Canvas API con renderizado de 60 FPS.
- **Efectos Visuales:** Sistema de partículas dinámico al comer y resplandor (glow) neón mediante `shadowBlur`.
- **Persistencia:** Sistema de puntuación máxima (High Score) guardado en `localStorage`.
- **Dificultad Dinámica:** La velocidad del juego aumenta progresivamente cada vez que la serpiente crece.
- **Responsive:** Adaptado para jugar en diferentes tamaños de ventana.

## 🎮 Controles
- **Flechas del Teclado** para moverte.
- **Teclas WASD** (Alternativo).
- **Botón START** para iniciar o reiniciar tras perder.
